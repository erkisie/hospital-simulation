# Hospital Simulation Project

This project analyzes patient flow data from Baltalimani Bone Diseases Hospital and prepares cleaned inputs for a SimPy-based hospital simulation model.

## Current Progress
- Data loading and preprocessing
- Time conversion and duration calculation
- Missing and invalid data cleaning
- Histogram analysis for X-ray waiting times and examination durations
- Doctor-based summary statistics

## Files
- `src/data_processing.py`: data cleaning and preprocessing
- `src/analysis.py`: descriptive analysis and plots
- `data/cleaned_data.xlsx`: cleaned dataset
- `results/`: generated outputs and plots
